# Diagnostic categories that only `heal::infer_category` names.
#
# Each would be reachable -- a message carrying the right words gets the right
# code -- but no analysis pass would construct one, so the compiler could relay
# such an error and not find one.
#
# This baseline is empty. It held BorrowConflict and UseAfterMove until
# `prototype/src/borrowck.rs` landed: a per-function ownership and borrow pass
# that emits E0502 and E0382. The checker fails both ways round (a category with
# no pass must be listed, and a listed one that gains a pass must be removed),
# so the file stays as the place a future classifier-only category is recorded.
